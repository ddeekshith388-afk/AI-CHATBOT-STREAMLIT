# 🤖 AI Chatbot - Streamlit

A simple and interactive AI Chatbot built with **Python and Streamlit**.

This project allows users to chat with different AI models through a clean and simple web interface. The application includes model selection, temperature settings, chat history, and secure API-key management using environment variables.

---

## ✨ Features

- 🤖 AI Chatbot
- 💬 Interactive chat interface
- ⚙️ Settings panel
- 🔵 OpenAI model support
- 🟢 Google Gemini model support
- 🧠 Multiple model selection
- 🌡️ Temperature control
- 🗑️ Clear chat option
- ⬜ Clean white user interface
- 🔐 Secure API-key management
- 📁 `.env` support
- 🚫 API keys protected using `.gitignore`
- 🐍 Python + Streamlit
- 📦 Requirements file for easy installation

---

## 🧠 Available Models

The application provides different model options from the Settings panel.

### 🔵 OpenAI

- OpenAI - GPT-5 Mini
- OpenAI - GPT-4.1 Mini

### 🟢 Google Gemini

- Gemini - Gemini Flash
- Gemini - Gemini Pro

### ⚪ Normal

- Normal - Basic Assistant

> Model availability and model names may change over time. Check the respective provider documentation when updating models.
